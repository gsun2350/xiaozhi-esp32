# xiaozhi.me 本地音乐曲库配置

## 准备 TF 卡

将 TF 卡格式化为 FAT32，在根目录建立 `music` 文件夹。文件名优先与曲库 `song_id` 完全一致，例如 `0001` 对应 `/sdcard/music/0001.mp3`。若纯数字 ID 不足三位且精确文件名不存在，固件会尝试补零到三位，如 `2` 对应 `002.mp3`。歌曲 ID 只使用 1–32 位 ASCII 字母、数字、下划线或短横线；新增歌曲仍建议统一使用文本格式的固定宽度 ID，避免依赖补零兼容。不要把歌曲名直接当作文件名。

## 准备曲库

复制 `music_catalog_example.xlsx`，按 `song_id`、`song_name`、`artist`、`aliases`、`tags` 五列录入。`song_id` 列预设为文本；新增行也应保持文本格式，检查 `0001` 没有变成 `1`。一个 ID 只对应一首歌，别名用顿号分隔。请只录入你有权在本地播放的 MP3。

本仓库同时提供 `music_catalog_example.md`，用于控制台只接受纯文本或 Markdown 的情况。

## 配置智能体

1. 登录 [xiaozhi.me 控制台](https://xiaozhi.me/console/)，选择设备绑定的智能体。
2. 在控制台当前版本提供的知识库入口上传曲库文件；若界面不接受 `.xlsx`，使用 Markdown 或 CSV 版本。
3. 打开设备所属智能体的“配置 → 扩展能力”，将“知识库”下拉框从“不使用知识库”改为实际上传曲库的知识库，并关闭官方“音乐”服务，避免点歌被路由到在线 `search_music`。只勾选“知识库”官方服务并不会自动绑定具体知识库。
4. 将 `music_agent_prompt.md` 的提示词加入智能体角色设置，并保存。
5. 设备刷入本分支固件并联网后，在 MCP 工具列表确认 `self.music.play` 等七个工具可见。若服务端限制工具数量，查看设备启动日志中的工具清单计数。

## 测试

先询问“曲库里《稻香》的 song_id 是什么”，应答 `0001`。再说“播放周杰伦的稻香”，检查云端调用 `self.music.play`，参数是 `{"song_id":"0001"}`。工具返回 `command_accepted` 仅表示命令被接收；用 `self.music.get_status` 确认 `PLAYING`，并实际听到音频。

播放期间按 Boot 键进入对话，音乐应暂停；说“暂停音乐”后状态应为 `PAUSED`，对话结束不自动恢复。再按 Boot 键说“继续播放”，确认从原位置继续。也测试下一首、上一首、停止以及无 TF 卡启动。

如果知识库没有唯一匹配结果，智能体应询问歌曲名或歌手，不得猜测 ID。若控制台知识库无法稳定返回精确 ID，可把较小曲库直接写入智能体提示词作为后备；较大曲库需另行评估官方控制台支持的检索形式，本固件不要求自建后台。
